# Changelog

## 1.0.0 (Oct 2026)
First public release. Local transcription (faster-whisper), cut list approval, head-tracked 9:16 reframe, person matte, storyboard gate, HTML + GSAP graphics engine with 24 element types (profile card, kinetic word, film strip, exploded layers, cut timeline, phone fan, silhouette, posters, boards, chips, outro with reactions), mixed-typography captions, ElevenLabs sound pack with synth fallback, two-pass loudness, H.265 delivery. Default look: nav-signature. Rules learned on the launch video: props never cover the face while speaking (boards sit below the chin, captions shift up); no background blur on a good set.
